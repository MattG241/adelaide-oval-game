# Cricket at Adelaide Oval: the game

A T20 game at Adelaide Oval with the real XIs of 31 matches, played in the browser with a controller or the keyboard. Results come from play, not from the real matches.

This repository holds only the built game (decision 13 in MattG241/adelaide-oval), served by GitHub Pages at https://mattg241.github.io/adelaide-oval-game/. On a phone, open it in Chrome: Start goes full screen.

- Match data: [Cricsheet](https://cricsheet.org), CC BY-SA 4.0 (the register: ODC-By).
- Commentary voice: ElevenLabs.
