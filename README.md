# Cricket at Adelaide Oval: the game

A T20 game at Adelaide Oval with the real XIs of 31 finals (BBL, WBBL, IPL and T20 World Cups), played in the browser with a controller or the keyboard. Results come from play, not from the real matches.

This repository holds only the built game, served by GitHub Pages. Open https://mattg241.github.io/adelaide-oval-game/ in Chrome; on a phone, Start goes full screen.

- Match data: [Cricsheet](https://cricsheet.org), CC BY-SA 4.0 (the register: ODC-By).
- Commentary voice: ElevenLabs.
